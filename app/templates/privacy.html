Privacy Notice & Platform Advisory

Transparency statement on data minimization, protected evidence handling, and system scope.

Effective Date: 2026 Academic Year • Status: Educational & Portfolio Demonstration Portal
1. Educational & Non-Official System Scope

CivicShield AI is an academic portfolio project developed to demonstrate full-stack Python application architecture, role-based workflows, protected asset storage, and practical machine learning text classification. It is NOT an official government agency, police department portal, or court of law. It does not replace statutory police reporting channels. In any real emergency, immediately dial 112 or 100.

2. Data Minimization Principles

In compliance with privacy engineering standards:

  • No Routine Aadhaar Collection: We do not require, collect, or store national biometric or Aadhaar numbers for citizen registrations.
  • Minimal Account Information: Citizens provide only basic contact details (full name, email, phone number) necessary to communicate case milestones.
  • No Third-Party Tracking: The application does not deploy advertising trackers, commercial cookies, or external ad scripts.
3. Protected Evidence Storage & Access Controls

Uploaded evidence documents and photos are held in isolated, non-public storage directories. Files cannot be accessed through guessable public URLs. Every view or download request requires authenticated session verification against the database:

  • Only the filing citizen, the designated investigating officer, and system administrators hold authorization to inspect attached evidence.
  • Every access to an evidence file creates an indelible record in the system audit log.
  • Files undergo content integrity inspection to prevent malicious uploads.
4. Machine Learning & Privacy

The complaint classification system operates locally using a lightweight Python scikit-learn model. Your incident narrative is processed securely on the server without sending user data to third-party commercial cloud AI providers.

5. User Inquiries

For academic inquiries, architecture reviews, or portfolio discussions regarding this system, contact the project maintainer via the administrative console or GitHub repository.
